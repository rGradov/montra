# Montra MCP

FastMCP даёт Codex доступ к локальному HTTP API Montra. Этот же API можно вызывать
из других приложений напрямую. [Настройка API и примеры HTTP-запросов](../Docs/Local-API.md)

## Подключение

Соберите и запустите Montra. Завершите знакомство с приложением и включите
**Локальный API** в разделе **Настройки → Интеграция** или через верхнее меню.
Оставьте Montra запущенной во время
импорта. FastMCP читает токен из приватного файла, созданного приложением.

Для FastMCP нужны `uv` и Python 3.12–3.14. Команды ниже запускаются из корня проекта.

```bash
uv sync --project mcp --locked --python 3.13
codex mcp add montra -- "$PWD/mcp/run.sh"
codex mcp list
```

В настольном Codex можно выбрать **MCP servers → Add server → STDIO** и указать
абсолютный путь к `mcp/run.sh`. Если сервер уже добавлен с этой командой, перезапустите
Codex. Для запросов записи можно установить `default_tools_approval_mode = "writes"`
в конфигурации Codex.
[Документация Codex MCP](https://learn.chatgpt.com/docs/extend/mcp?surface=cli)

## Работа с PDF

Дайте локальному Codex путь к файлу выписки и попросите подготовить импорт.

> Разбери эту PDF-выписку и подготовь импорт в Montra на счёт «Карта» в BYN.
> Сверь суммы и количество проведённых операций с выпиской. Покажи предпросмотр и
> возможные дубли. Запиши операции после моего подтверждения.

1. Сопоставьте счёт и валюту по `list_accounts`, категории по `list_categories`.
   Используйте сумму в валюте счёта из колонки списания или зачисления. Когда счёт
   создаётся для полной истории, начальный остаток берётся на момент **до** первой
   импортируемой операции.
2. Извлеките проведённые операции. Пропустите итоги и остатки. Сомнительные строки,
   переводы между своими счетами и различия между датой покупки и датой проведения
   вынесите на проверку. Если есть только дата, используйте 12:00 в часовом поясе
   выписки и сообщите об этом. Указывайте дату с секундами и смещением, например
   `2026-11-09T12:00:00+03:00`.
3. Вызовите `preview_import` для одного счёта и одной валюты. В пакете до 100 строк.
   Сумма передаётся положительной десятичной строкой с точкой. Для BTC доступно до
   8 знаков после точки, для остальных валют до 2. Тип строки определяет знак.
   Категория может отсутствовать. Отдельные счета и категории создавайте по запросу
   пользователя.
4. Покажите количество строк, суммы расходов и поступлений, уже импортированные
   строки и совпадения. Сверьте с пользователем возможные дубли через `list_operations`.
   Исключите подтверждённые дубли из пакета. Для разных платежей с одинаковой суммой
   можно после проверки передать `allow_possible_duplicate: true` для конкретной
   строки. После любого изменения пакета получите новый предпросмотр.
5. После подтверждения вызовите `import_operations` с тем же пакетом и
   `preview_token`. Записи сохраняются одной транзакцией. Инструмент вернёт число
   созданных и уже импортированных операций.

### Как определяются дубли

Сохраняйте один и тот же `source` для банка или формата выписки, например
`bank-statement`. В `external_id` передавайте стабильный банковский ID операции.
Если его нет, используйте стабильный ID выписки и номер исходной строки. Не меняйте
эти значения при повторной обработке. Для разных документов со строками без ID
совпадения по счёту, локальному дню, сумме и типу требуют проверки. Разные даты
проведения или суммы могут скрыть совпадение, поэтому выписки с пересекающимися
периодами также сверяйте по исходным документам. Повтор запроса с тем же ID и
изменёнными финансовыми полями отклоняется.

Сервер принимает структурированные строки. PDF читает ассистент в чате. Встроенного
OCR в сервере нет. Для скана проверьте распознанные суммы перед импортом.

## Инструменты

| Инструмент | Действие |
| --- | --- |
| `status` | Версия и список команд, доступных в запущенной Montra |
| `list_accounts`, `get_balances`, `list_categories` | Счета, итоги по валютам, категории и подкатегории |
| `list_operations` | Поиск по одному или всем счетам с фильтрами и пагинацией |
| `create_account`, `create_category` | Создание счёта (включая `is_savings`, `is_hidden_from_overview` и `icon_name` — SF Symbol или emoji), категории или подкатегории через `parent_id` |
| `create_operation` | Одна операция. Сохраните `request_id` и используйте его при повторе |
| `recategorize_operations` | Перенос от 1 до 100 выбранных расходов или доходов в категорию или подкатегорию того же типа |
| `create_transfer`, `get_transfer` | Запись перевода между счетами и чтение обеих его частей |
| `create_plan`, `list_plans` | Создание повторяющегося платежа и список его дат |
| `link_plan`, `record_plan` | Связать план с существующей операцией или записать его как факт |
| `preview_import`, `import_operations` | Предпросмотр и запись пакета |
| `preview_delete_account`, `delete_account` | Предпросмотр и удаление счёта с его операциями и планами |
| `preview_delete_operations`, `delete_operations` | Предпросмотр и удаление операций. Переводы удаляются парами |
| `preview_delete_plan`, `delete_plan` | Предпросмотр и удаление одной даты или серии. Связанные факты сохраняются |

Для удаления счетов, операций и планов включите **Разрешить удаление через API**
в разделе **Настройки → Интеграция** или в верхнем меню Montra.
Покажите пользователю предпросмотр и передайте его токен после подтверждения.
Если данные изменились, получите новый предпросмотр.

## Подключение к ChatGPT в браузере

Локальный `stdio` подключается напрямую к Codex. Для ChatGPT в браузере можно
подключить тот же `mcp/run.sh` через OpenAI Secure MCP Tunnel, если ваш рабочий
аккаунт поддерживает добавление пользовательских MCP-серверов. Для этого нужны
созданный туннель, отдельный ключ для `tunnel-client` и доступ на стороне ChatGPT.
Укажите абсолютный путь к `mcp/run.sh` как `--mcp-command` в профиле туннеля и
выберите **Tunnel** при добавлении сервера. На Mac должен работать клиент туннеля.
[Инструкция Secure MCP Tunnel](https://developers.openai.com/api/docs/guides/secure-mcp-tunnels)

## Проверка

```bash
./mcp/tests/build-fixture.sh
mcp/.venv/bin/python mcp/tests/smoke.py
```

Тест вызывает HTTP и MCP на одной базе SwiftData в памяти. Он проверяет авторизацию,
предпросмотр, повторы, совместимость со старыми ID и удаление счёта.
