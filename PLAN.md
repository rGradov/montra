# План реализации Montra

Эталон стиля — Purge (скриншоты и исходники `github.com/jithin-sabu/purge-app`):
из него взяты палитра, шрифт, размеры окна, компоненты и анимации. Всё, что про деньги,
спроектировано заново.

## Фазы

- [x] **0. Изучение референса**
  Разобраны `AppColors`, `AppStyle`, `PurgeButtonStyle`, `FilterChip`, `AppChrome`,
  `ScanResultRow`, `SettingsView`: палитра, типографика, окно 980×700, сайдбар 240,
  кнопки 24/30/38, радиусы 4/6/8/14, шрифт Onest с удалёнными цифрами и числа SF Rounded,
  анимации 0.12/0.15/0.45/0.6.
- [x] **1. Каркас проекта**
  Xcode-проект с synchronized group, macOS 15+, сборка без ошибок и предупреждений.
- [x] **2. Дизайн-система**
  Токены цвета/типографики/метрик, `MontraButtonStyle`, карточки, строки, плашки, бейджи,
  чипы, тумблер, поповер-меню, поля, hover/нажатия, `accessibilityReduceMotion`.
- [x] **3. Данные**
  SwiftData-модели (Account, Category, Operation, Period), CloudKit-safe, сиды,
  репозитории, `PeriodService`, `SettingsStore`, `SyncService`.
- [x] **4. Оболочка**
  Окно без title bar, сайдбар с секциями и CTA «Новый счёт», роутинг, статус-пилюля.
- [x] **5. Обзор**
  Hero-баланс, полоса распределения с hover, счета, период, последние операции,
  пустые состояния, чипы валют.
- [x] **6. Операции**
  Фильтры-чипы, выбор, сортировка, массовое удаление, создание/редактирование
  (расход/доход, дата и время, место, геолокация, комментарий), контекстное меню.
- [x] **7. Счета**
  Создание (иконка/цвет/валюта/сумма), страница счёта, правка, удаление с каскадом.
- [x] **8. Категории**
  14 стартовых, обязательность, кастомные, редактирование, удаление с переносом операций.
- [x] **9. Финансовый период**
  День зарплаты / фикс. длина, материализация периодов, правка границ, сброс к правилу,
  лист периодов.
- [x] **10. Настройки / Аналитика / О программе**
  Тема, скрытие сумм, период, экспорт CSV, iCloud-статус, заглушка аналитики.
- [x] **11. Визуальная сверка**
  Снапшот-рендер всех экранов через NSHostingView, сравнение с референсом, доводка
  отступов, меню, тумблера, миниатюр оформления, полей даты.
- [x] **12. Финал**
  Иконка приложения, `-selftest`, README, MasterPrompt, iCloud-инструкция, сборка.
- [x] **13. Счета в сайдбаре и курсы**
  Все счета под «Обзором» с балансами; общий итог по всем валютам; конвертация через
  НБРБ + резервный открытый фид, кеш на 6 часов, строка курса и разбор счёта при
  наведении, «≈» в списке счетов и на странице счёта.
- [x] **14. Анимация добавления операции**
  Новая строка выезжает с лёгким масштабом и blur (spring 0.34), держит подсветку 1.4 с и
  гаснет; работает в операциях, обзоре и на странице счёта. Массовые вставки не мигают.

- [x] **15. Операции как подстраница обзора**
  Вкладка «Операции» убрана из сайдбара. Полный список открывается из обзора по
  «Все операции» и по ⌘2, в сайдбаре подсвечен «Обзор», на странице есть ссылка назад.

- [x] **16. Знакомство в стиле онбординга Purge**
  Экран приветствия, создание первого настоящего счёта, выбор стартовых категорий
  (пропуск оставляет «Прочее»), первый расход с пропуском, финал со sparkles и
  анимированным балансом; переходы blur+opacity 0.45, каскадное появление, кнопки
  240×38. Показывается только на чистом хранилище.

- [x] **16b. Hero-перелёт счёта после знакомства**
  Карточка счёта с финального экрана улетает в свою строку в сайдбаре (позиция и
  масштаб, spring), строка скрыта до приземления; остальное приложение проявляется
  одновременно. Reduce Motion и неизмеренные фреймы — обычный fade.

- [x] **16c. Накопительные счета**
  Переключатель «Накопительный счёт» в создании/редактировании и в знакомстве;
  такие счета уходят в группу «Накопления» в сайдбаре и подписаны в обзоре/шапке
  счёта. Снимать, пополнять и переводить можно как обычно — меняется только метка
  и будущая динамика накоплений в аналитике.

- [x] **17. Анимация подписи страницы**
  Заголовок и подпись всплывают с blur при открытии страницы (подпись с задержкой 0.07),
  счётчики в подписи перекатываются цифрами при изменении. В хедере обзора показан
  диапазон текущего периода; после закрытия листа периодов подпись появляется заново,
  чтобы изменение было видно.

- [x] **18. Гармошка при смене фильтра**
  На странице счёта строки остаются в иерархии и анимируют высоту (spring 0.4, стаггер
  0.02), зазор складывается вместе со строкой, пустое состояние появляется с fade.

- [x] **19. Поиск по операциям**
  Капсульный поиск как в Purge, фильтрация по категории/счёту/месту/комментарию/сумме,
  пересчёт счётчиков чипов и подписи в хедере, пустое состояние с «Очистить поиск»,
  предложения «Показать все» и «Искать за всё время», ⌘F и Escape.

- [x] **20. Полоса баланса как в Purge**
  Сегменты — прямоугольники в одной капсуле, зазор 2 pt, минимальная ширина 4;
  убраны «пилюли» и постоянный трек, скруглены только внешние концы.

- [x] **21. Степпер вместо меню на 31 строку**
  «День зарплаты» и «Длина периода» в настройках и в листе периодов — компактный
  `− значение +` с границами и перекатом цифр; длинные выпадающие списки убраны.

- [x] **22. Ввод числа в степпере**
  Значение «Дня зарплаты» и «Длины периода» можно вписать руками: только цифры,
  ограничение диапазоном по Return/потере фокуса, подпись в покое остаётся целой,
  при клике показывается поле с числом и единицей; `−`/`+` работают как раньше.

- [x] **23. Экран «О программе» и повторное знакомство**
  About в стиле референса: заглушка логотипа, название/версия, карточка с общей суммой,
  «Что умеет Montra», одна кнопка «Пройти знакомство заново». Повторный онбординг
  запускается поверх окна на временном in-memory контейнере и не плодит реальные счета;
  закрывается крестиком/Escape. Заглушка используется и на приветствии.

- [x] **24. Анимация смены валюты**
  В онбординге и листе нового счёта символ валюты в поле суммы меняется перекатом
  (старый вверх, новый снизу, 0.22) в фиксированном слоте; капсулы валюты тоже
  анимируют выбор.

- [x] **25. Иконка и цвет в онбординге + анимация финала**
  На шаге первого счёта слева от имени — плитка с карандашом, открывающая поповер
  с иконками и цветами; созданный счёт использует выбор. Звёздочки на финале
  дышат (масштаб, лёгкий поворот, свечение), с Reduce Motion — статично.

- [x] **26. Свой календарь и время**
  Вместо системного `DatePicker` с белым циферблатом — `MontraDateTimePicker`:
  месяц со стрелками, сетка 6×7 в палитре приложения, выбранный/сегодняшний день,
  поле `чч:мм` с валидацией, «Сейчас»/«Сегодня» и «Готово», поддержка диапазона.
  Используется в операции и в листе периодов.

- [x] **27. Удаление операций как в Purge**
  Выбор и Select All, в хедере «Выбрано N · сумма», кнопка «Удалить (N)». Подтверждение —
  лист со списком удаляемых операций и итогом; после удаления — экран успеха с
  нарисованной галочкой, суммой, количеством, временем и «Готово».

- [x] **28. Выбор и удаление на странице счёта**
  Чекбоксы в компактных строках, «Выбрать все» по текущему фильтру, «Выбрано N · сумма»
  и кнопка «Удалить (N)» в хедере; подтверждение и экран успеха — общие с «Все операции».

- [x] **29. Производительность больших счётов**
  Аккаунт-страница запрашивает только свои операции через `@Query` (сортировка в
  хранилище), для >60 записей переключается на `LazyVStack` (только видимые строки),
  гармошка остаётся для небольших счетов. Убраны пересборки массивов id в анимациях
  и трекинге новых строк. Проверено на 1000+ операциях.

- [x] **30. Переводы между счетами**
  Третья вкладка «Перевод» в «Новой операции» с тем же выбором счёта, двумя суммами,
  курсовой подсказкой и ручной суммой зачисления. Две связанные операции с общим `transferID`; в списках — «Перевод»,
  read-only детали; расходы/доходы периода не искажаются; удаление одной части
  удаляет обе.

- [x] **31. Подкатегории и новый выбор категорий**
  Один уровень вложенности; в листе категории — «Родительская категория» с «Без родителя»;
  иерархия на странице категорий; обязательность наследуется; удаление родителя
  поднимает детей. В форме операции — 5 самых частых категорий + «Ещё»: поповер с
  капсульным поиском и всей иерархией, без отдельной страницы.

- [x] **32. Транзакции по дням**
  «Все операции» и страница счёта группируются по дням: «Сегодня», «Вчера», «Завтра»
  и даты «7 октября» (с годом для другого года); заголовки липкие; при сортировке по
  сумме — плоский список. У небольших счетов гармошка сохраняется.

- [x] **33. Регулярные платежи**
  «Повторять» в форме операции (день/неделя/месяц/год, дни недели, «повторять до»).
  Планы генерируются заранее, но не меняют баланс; видны в «Все операции» и на счёте;
  «Пропущенные»/«Будущие», связывание с фактом, сохранение как факт, удаление одного
  платежа или всей серии; ограничение будущего двумя годами/концом серии.

- [x] **34. Знакомство после удаления и маршрут после него**
  «Удалить все данные» сразу показывает настоящее знакомство на реальном хранилище;
  счёт сохраняется. И настоящее знакомство, и предпросмотр из «О программе» завершаются
  на «Обзоре». У предпросмотра — явная плашка, что данные не сохраняются.

- [x] **35. Знакомство без накопительного счёта**
  На шаге счёта в знакомстве больше нет тумблера «Накопительный счёт»: первый счёт всегда
  обычный, накопительный заводят в листе счёта, когда он понадобится. На шаге категорий
  по умолчанию отмечены только Жильё, Еда и Зарплата — остальное выбирается в один клик.

- [x] **36. Резервная копия**
  Один файл `.montra` с полным состоянием: счета, операции с обеими частями переводов,
  категории с родителями, планы, периоды, настройки, курсы на день копии и переключатели
  локального API. Настройки → «Резервная копия»: сохранение и загрузка через панели, лист
  с содержимым и предупреждением о замене, сохранение текущего состояния перед
  восстановлением. Формат версионирован и защищён SHA-256; до удаления текущих записей
  проверяются суммы и все ссылки. Успех открывает обновлённый «Обзор». Подробности —
  `Docs/Backup.md`.

## Проверки

- `-selftest` — 131 проверка: непрерывность периодов, клампинг 31-го числа, фиксированная
  длина, сдвиг границ, баланс, знаки сумм, обязательные расходы, перенос операций при
  удалении категории, конвертация USD/EUR/BYN, итог по всем счетам, логика подсветки
  новых строк, чистый старт без демо-данных и возврат знакомства после очистки, формат
  валют, склонения, а также полный круг резервной копии: сборка, запись и чтение файла,
  точность дробных сумм, обнаружение подмены и чужого файла, восстановление связей,
  настроек, курсов и API, отказ от битой копии до удаления данных. Всё проходит.
- `-snapshot` — 34 PNG: обзор (в т.ч. полная страница), операции, счёт, категории,
  настройки (обычные и полные), аналитика, «О программе», светлая тема, листы, включая
  восстановление резервной копии.
- `xcodebuild` — BUILD SUCCEEDED, без предупреждений Swift.

## Следующие шаги (вне этой итерации)

1. Аналитика: расходы по категориям и динамика по периодам (данные уже сгруппированы).
2. Переводы между счетами с курсом и историей.
3. Регулярные операции (аренда, подписки) с автоподстановкой.
4. Включение iCloud по инструкции `Docs/iCloud-Setup.md`.
5. Собственные ассеты иконок счетов: `IconTile` уже рисует картинку, если в ассетах есть
   файл с именем иконки.
6. iOS-таргет на общих моделях.
